# 问题 49：主要页面的响应式布局

列入第 2.3 期。第 2.2 期不实现这套布局。

首页、单人和双人在矮屏上会重叠或贴死。本期只改布局尺寸，以及双人用哪一套结构。不改玩法、状态流转和统计。

设置页维持问题 47，本期不改。问题 18 已由本期布局覆盖。问题 19（327×327）won't fix。问题 50（难度菜单卡片）已按紧凑布局的槽位落地。

`game.json` 里 `deviceOrientation` 是 `portrait`。手机上的主要画面是竖屏。横屏尺寸来自平板横放和开发工具里拉宽的窗口。

## 双人只有两种结构

```ts
const wide = width > height ? duelWideLayout(...) : null
const layout = wide ?? duelStackedLayout(...)
```

- 竖屏（`height >= width`）：直接用居中单列 `duelStackedLayout()`。手机和 iPad 都走这里，包括宽度超过 748、甚至达到 1024 的 iPad Pro 竖屏。
- 横屏（`width > height`）：先试问题 46 的对称三栏。`duelWideLayout()` 在卡牌、间距和按钮收到下限后仍然重叠或越界时返回 `null`，不把侧栏缩到 44 再硬画。返回 `null` 后改用同一套居中单列。
- 居中单列的内容宽度不超过 430，在屏幕上水平居中。横屏退回这套时，按钮不会横向拉满。
- 只有这两套。删除双人的 748–927 旧双栏，横屏放不下三栏时也不恢复它。

844×390 不纳入本期。可用高度约 `390 − 72 − 34 = 284`。两行 92px 卡牌加 10px 行距再加 56px 运算符已经约 323，还没算记分牌、抢答、操作行和底栏。居中单列也无法不重叠。它只作为开发工具里的异常窗口。以后若要支持这种极矮横屏，需要另做「一行四张牌」的牌桌，不能靠现在的两行牌缩放解决。

## 高度不够时怎么缩小

居中单列、横屏三栏的中央牌桌、单人窄屏，都先按现在的标准尺寸排。标准尺寸放得下时，卡牌宽 120，顶边贴 `minTop`（至少 72，在小房子下面）。单人窄屏多出来的高度留在运算符和操作行之间，底栏贴底。单人宽屏把牌桌、运算符、右侧统计和按钮当成一整块，在 `minTop` 和底部安全区之间垂直居中，小房子不动。

放不下时按顺序缩小，前一项到下限再动下一项：

1. 卡牌宽 120→92，宽高比仍是 63:88。卡牌间距 16→10。
2. 牌到运算符、运算符到下一块、操作行到底栏的纵向间距收到 10。
3. 记分牌、抢答、操作按钮收到 44。底栏高 52、运算符高 56 不动。
4. 仍重叠时，第 2 步的间距再收到 8。375×667 会用到这一步。

触控高度不低于 44。绘制和点击用同一组矩形。

双人居中单列还要算上「点击认输」行：标准高 24，最低 16。抢答仍是左右对半的胶囊，倒计时 22、「抢答」20。不用宽屏的圆角 16 和更小字号。

高度够用时，记分牌、抢答和认输行作为一块，放在运算符底边和操作行顶边之间垂直居中。空间紧时记分牌到抢答收到 8，上下剩余均分。高度够了先把中间间距回到 16，再把其余高度的三分之一加进去，最多 48。高度不够时这块仍贴住操作行。

按 `minTop = 72`、底部安全区 34 估算：

- 390×844：卡牌仍是 120，顶边仍是 `minTop`。
- 430×707：卡牌约 100，间距约 10，抢答约 46，记分牌约 48。卡牌 108 再配记分牌 50 会高出约 20px。
- 375×667：卡牌 92，按钮 44，间距收到 8，大约还剩 8px。
- iPad 竖屏（如 834×1194、1024×1366）：走居中单列。高度够用标准尺寸，内容宽不超过 430，水平居中。

## 单人

单人不改页面结构，宽屏仍按宽度：达到 748 时左侧牌桌、右侧答案和统计。牌的大小用该栏的可用高度算，不只看屏幕宽度。

和双人共用牌的尺寸计算：先扣掉底栏、操作行和安全区，剩余高度再决定卡牌。双人多扣记分牌、抢答和认输行。

## 首页

首页维持四颗按钮，分成三块：标题区、单人 / 双人、游戏说明 / 设置。

现在「双人」到「游戏说明」的间距从 90 往下减，短屏可以减到 0，「来挑战一下」会贴住「单人游戏」。`来挑战一下` 的字号是 15，垂直居中绘制。

压缩顺序：

1. 「双人」到「游戏说明」：标准 90，最低 32。
2. 单人、双人按钮高度：64→56。
3. 单人到双人：28→20。
4. 「游戏说明」到「设置」：20→16。
5. 最后才上移标题区。

「来挑战一下」的视觉底部到「单人游戏」顶部至少 40，推荐 48。高屏用 48，单人和双人跟在这段文字下面。多出来的高度放在「双人」和「游戏说明」之间，可以大于 90。游戏说明和设置贴在页面底部。底部安全区不变。按钮宽仍是 280，更窄时随屏幕缩小。

## 测试

- 双人竖屏：375×667、390×844、430×707、1024×1366。都走居中单列，矩形在 `minTop` 和底部安全区之间，互不重叠。390×844 的卡牌宽为 120、顶边为 `minTop`。1024×1366 不得进入三栏，内容宽不超过 430。
- 双人横屏：940×665、1194×834 走三栏，保持问题 46 的左右对称，并且不重叠。844×390 不在验收里。
- 单人：390×844 卡牌仍是 120；430×707 卡牌缩小且不与底栏重叠；宽度达到 748 时仍是左右分栏。
- 首页：短屏上「来挑战一下」到「单人游戏」至少 40；高屏这段是 48，单人和双人跟在文字下面，游戏说明和设置贴底。
